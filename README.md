# ComposeTask MobileApp

A Spring Boot backend for the ComposeTask mobile application.

## Tech Stack

- **Java**: 21
- **Spring Boot**: 3.5.4
- **Spring MVC**: Web framework
- **Spring Data JPA**: ORM for database interactions
- **PostgreSQL**: Database
- **Spring Security**: Authentication and authorization
- **JWT**: JSON Web Tokens for secure authentication
- **Lombok**: Code generation for boilerplate
- **Validation**: Bean validation
- **Springdoc OpenAPI**: API documentation
- **Jackson**: JSON processing with JSR-310 support
- **Maven**: Build tool

## Prerequisites

- Java 21
- Maven
- PostgreSQL

## Build and Run

```bash
./mvnw clean package
./mvnw spring-boot:run
```

## API Documentation

Access Swagger UI at http://localhost:8080/swagger-ui/index.html when running.
